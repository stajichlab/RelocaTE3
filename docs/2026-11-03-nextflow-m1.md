## Purpose

Run RelocaTE3 as a Nextflow pipeline whose per-sample output is identical to
`relocaTE3 run-all`. The workflow contains no detection logic: each task runs
one subcommand with `run-all`'s settings.

## Decisions

- Minimum Nextflow version is 25.10, not 25.04: nf-schema ≥ 2.6 requires it.
  Recorded in the design doc.
- The pipeline adds `te_opts`, `genome_opts`, `distance` and `excision` so that
  every `run-all` argument is covered.
- Lane grouping happens in `main.nf`, before any channel is built. Errors
  raised inside channel operators reach the console only as
  "InvocationTargetException".
- A `genotype_bam` needs `<file>.bai`/`.csi` or `<file>.crai` next to it. It is
  checked before any task runs.
- Sample-sheet paths are resolved relative to the launch directory (nf-schema
  behaviour). The test profile must be launched from the repository root.

## Known issues

- `--help` prints the help, then exits 1 ("missing required parameters").
- `relocaTE3 --version` in the pixi env reports the version from its install
  build (`0.2.0rc2.post8+g9d83725…`), not HEAD. This is the editable-install
  metadata.
- Nextflow's report, timeline and trace are overwritten on rerun.
- The parity gate does not cover lanes, `genotype_bam` or single-end input.
  Stub tests cover the wiring for these.
